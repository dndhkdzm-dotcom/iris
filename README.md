# IRIS 방탈출 앱 (안드로이드)

신인 걸그룹 IRIS의 음반 투자 설명회 40분 전, 메인 PD가 쓰러졌다 — PD의 노트북을 열어 음원 파일을 전송하라!
외부 통신·NFC·CCTV 없이 **타이머 + 힌트 + 관리자 설정**만 있는 단독 앱입니다. (인터넷/NFC 권한 없음)
디자인: 거의 검정에 가까운 네이비·보라, 각지고 거친 질감.

## APK 만드는 방법
1. 이 폴더 안의 내용을 GitHub 저장소(비공개)에 **폴더째 끌어다 놓기**로 올립니다. `.github` 폴더는 GitHub에서 직접 만들어야 할 수 있습니다.
2. Actions 탭 → Build APK → 초록 체크 → 맨 아래 Artifacts `iris-escape-apk`.
3. `app-debug.apk`를 폰에 옮겨 설치(출처를 알 수 없는 앱 허용). 이전 분홍 버전 위에 덮어쓰기 설치하면 입력해 둔 힌트·사진이 유지됩니다.

## 코드 (`app/src/main/assets/index.html` 맨 위 설정값)
| 용도 | 코드 | 변수 |
|---|---|---|
| 처음 인증 | `9999` | `AUTH_CODE` |
| 전체 초기화 (관리자 버튼 → 입력) | `9999` | `RESET_ALL` |
| 문제별 힌트 설정 열기 | `0000` | `SETUP_CODE` |

## 힌트
- 문제 번호(1~10) 입력 → 확인창 → 1페이지(힌트 글 + **이미지**) / 2페이지(해설 글 + **이미지** + 정답)
- 문제별 힌트 설정에서 1페이지 이미지와 2페이지(해설) 이미지를 각각 첨부·삭제할 수 있습니다.
- 초기화는 타이머·확인한 힌트 수·인증 상태만 처음으로 돌리고, 입력한 힌트와 이미지는 유지합니다.
